# humidity_controller

Одна сущность `humidifier` на зону: сводит несколько датчиков влажности
(`mean` / `min` / `max` / `median`) и управляет увлажнителями тремя способами —
скорость вентилятора по PI (`manual`, по умолчанию), уставка с поправкой (`auto`) или вкл/выкл
по гистерезису — с пресетами, расписаниями по времени суток и защитой при
пропаже показаний.

Модули:

- `humidifier.py` — сущность и цикл регулирования (вызовы сервисов HA);
- `control.py` — чистая математика: сведение, поправка уставки, гистерезис с
  минимальным временем вкл/выкл, PI скорости;
- `schedule.py` — точки расписания и интерполяция;
- `entry.py` — форма данных записи, настройки устройств по умолчанию, миграция
  и выбор сущности скорости среди `number.*` устройства;
- `devices.py` — поиск сущности скорости в реестре HA;
- `config_flow.py` — добавление записи и меню «Настроить».

Подробно — в README репозитория: https://github.com/smart-ha/humidity-controller
